





### Suggested file structure
Using `xdg.configFile` to add all files to `.config/hypr/`, use this suggested structure:

```
config/hypr/
├── hyprland.lua
├── modules/
│   ├── keybinds.lua
│   ├── monitors.lua
│   └── appearance.lua
├── hypridle.conf
├── hyprpaper.conf
└── hyprlock.conf
```

As of the 26.05 stable release, only the hyprland config supports lua.
